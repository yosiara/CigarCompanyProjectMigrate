# Odoo Migration – Lázaro Peña Cigar Company

**Project:** Upgrading the Odoo ERP from versions 10+ to Odoo 18+  
**Responsible:** Computer Science Specialist – IT Department  
**Technology:** Docker, Odoo 18, PostgreSQL 16

---

## Description

Complete migration of the Odoo system (version 10 or higher) to version 18, using Docker containers to ensure reproducibility and easy maintenance. Data, customizations, and workflows (sales, inventory, production, purchasing, HR, accounting) are migrated.

## Main Objectives

- Upgrade to Odoo 18 (Python 3.10+, PostgreSQL 16)
- Containerize the entire stack with Docker
- Zero data loss and minimal downtime

## Requirements

- Docker ≥ 20.10
- Docker Compose ≥ 2.20
- Git
